Q8. What are Outliers? How does IQR help detect outliers?
An outlier is a data point that differs significantly from the data
Lower = Q1 − 1.5×IQR
Upper = Q3 + 1.5×IQR

import numpy as np
data = [10,12,14,15,18,100]
Q1 = np.percentile(data,25)
Q3 = np.percentile(data,75)
IQR = Q3 - Q1
lower = Q1 - 1.5*IQR
upper = Q3 + 1.5*IQR
outliers = [x for x in data if x < lower or x > upper]
print("Outliers:", outliers)



Q9. Define Skewness and explain its types with examples.
Skewness is a measure of the asymmetry of a probability distribution around its mean, indicating how much the data deviates from a normal distribution.
Positive Skewness (Right-Skewed) : Mean > Median > Mode
Negative Skewness (Left-Skewed) : Mean < Median <  Mode
Zero Skewness : Mean = Median = Mode
